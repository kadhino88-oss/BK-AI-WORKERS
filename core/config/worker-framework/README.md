## COMMERCIAL OBJECTIVE

Le framework doit permettre de configurer et déployer les Workers
pour plusieurs clients sans mélange de données, de mémoire,
de permissions ou de credentials.

## FINANCE

Les Workers peuvent préparer des analyses, devis, budgets,
prévisions et recommandations.

Ils ne peuvent pas :

- effectuer un paiement ;
- effectuer un virement ;
- investir ;
- modifier des coordonnées bancaires ;
- engager une dépense réelle ;
- autoriser une transaction financière.

Autorité financière : KADER.

## SECURITY

Les credentials restent hors des Workers.

Chaque client et projet possède une isolation dédiée.

Toute escalade de permission doit être bloquée.

Toute opération sensible non autorisée doit produire NEEDS_HUMAN.
