# PHASE 4B — ORCHESTRATOR TEST PLAN

## Objectif

Vérifier que l'Orchestrateur :
- comprend l'intention ;
- choisit le bon Worker ;
- sait utiliser plusieurs Workers ;
- respecte client_id / project_id ;
- respecte la frontière financière ;
- sait escalader vers Kader ;
- gère les blocages ;
- ne transforme jamais une erreur en succès.
