Supprimer mon compte et mes données

Vous restez maître de vos données.

Comment faire

  1. Connectez-vous à votre compte sur bk-ai-workers.com ou dans l'application installée.
  2. Ouvrez la page « Facturation » depuis le menu.
  3. Dans la section « Mes données », touchez « Exporter mes données » si vous voulez d'abord garder une copie.
  4. Touchez « Supprimer mon compte », puis saisissez votre mot de passe pour confirmer.

La suppression est définitive : elle ne peut pas être annulée.

Ce qui est supprimé

  • Votre compte et vos connexions ouvertes.
  • Le profil de votre entreprise.
  • Vos missions et leurs résultats.
  • Vos automatisations.
  • Les connexions à vos outils (identifiants chiffrés).
  • Votre clé API et votre webhook, s'ils existent.
  • Le lien avec votre WhatsApp, s'il existe.

Si vous avez un abonnement

Résiliez d'abord votre abonnement depuis la page « Facturation » : la suppression du compte est refusée tant qu'un abonnement est actif.

Ce qui peut être conservé

Certaines pièces de facturation peuvent devoir être conservées pour répondre à des obligations légales (comptabilité : 10 ans). Les paiements sont traités par Stripe ; voir la politique de confidentialité.

Les sauvegardes techniques (les nôtres et celles de l'hébergeur) peuvent contenir vos données pendant une durée limitée, jusqu'à leur remplacement automatique.
