# INTER-WORKER PROTOCOL

## Communication standard

TASK
CONTEXT
RESULT
STATUS
BLOCKER
NEXT_ACTION

## Exemple

TASK:
Créer une landing page.

CONTEXT:
Client X / Projet Y.

RESULT:
Structure proposée + contenu + design.

STATUS:
SUCCESS

BLOCKER:
Aucun.

NEXT_ACTION:
LUCAS implémente la page.

## Règle

Les Workers ne communiquent pas uniquement par texte libre.

Chaque échange important doit pouvoir être structuré
et interprété par l'Orchestrateur.
